NAS Monitor — Button & Icon Reference

Three button sizes for different contexts

1. Modal Buttons 7px 14px · 13px font · 8px radius

Used at the bottom of modals for primary actions

Green — Positive Actions

Red — Negative Actions

Orange — Restart

Yellow — Stop

Lavender / White — Secondary

New Compose Modal

2. Container Detail Buttons 7px 14px · 12px font · 8px radius

Used at the top of the Container Detail modal for container actions

3. List / Table Row / In-Form Buttons 3px 10px · 12px font · 6px radius

Smaller buttons used inline with table rows, lists, and forms

Blue — Navigation / Actions

Green — Positive

Red — Negative
